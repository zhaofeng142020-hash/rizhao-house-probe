# 会话桥 · 浏览器扩展（装一次，之后全自动）

## 它解决什么

58 连续翻页会弹「访问过于频繁」验证，安居客翻页多了会弹极验。
**本扩展不识别、不破解任何验证码**，验证码始终由你本人在网页上完成。之后：

1. 扩展把会话 Cookie 自动同步到你的房价探针站点；
2. 你在 58 页面看到的房源，扩展按卡片 class 精确读 DOM 回传到站点并触发重算；
3. 服务端复用这份会话，每天 07:30 / 19:30 低频抓取贝壳 + 安居客 + 58 首屏，
   重算后**主动把结果推送给你**（企微 / 站内提醒），不用你打开网站、不用每天跑脚本。

低频是关键：只抓 58 首屏一页、每天两次，不去撞它的风控。
会话失效时推送里会提示「请在网页端打开一次页面」，你点一下即可恢复全自动。

## 安装（一次性）

1. Chrome 打开 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录 `tools/bridge-extension`
4. 点扩展图标 → 「设置」，填三项：
   - 站点地址：`https://rizhao-house-radar.app.workbuddy.host`
   - 分享码：线上链接 `?sharecode=` 后面那串
   - 管理口令：网站管理口令
   - 勾上「自动同步」→ 保存

## 数据边界

- 只读取公开列表页里**已经渲染出来**的文字和链接；不抓经纪人电话等隐私字段
- 每条都带原始页面链接，后端逐行校验（面积/总价合理性、必填字段），不合格自动拒绝
- 会话 Cookie 只存你本机浏览器 + 你自己的站点，不发给任何第三方
